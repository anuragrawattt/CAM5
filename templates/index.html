Welcome to the Railway Reservation System

This is a simple Railway Reservation System built as a college DBMS project. It uses Python Flask for the backend, MySQL for data storage, and HTML/CSS for the frontend. You can view, search, and add records for trains, stations, passengers, tickets, and more.

About This Project

Database: MySQL — railway_reservation

Backend: Python Flask

Frontend: HTML + CSS + Jinja2 Templates

The system manages 10 database tables: Railway Zones, Stations, Trains, Coaches, Passengers, Tickets, Employees, Platforms, Payments, and Cancellations. All counts shown above are fetched live from the database using SQL aggregate queries.
